# CrisisCrew-Disaster-Management-Coordination-System
CrisisCrew is a web-based disaster management and coordination system designed to streamline disaster response operations. The system enables administrators, clients, and volunteers to efficiently manage disaster events, resources, and tasks through a centralized platform.

## 🚀 Installation & Setup Guide

1. Install **XAMPP/WAMP** on your system
2. Clone or download this repository:

   ```bash
   git clone https://github.com/your-username/CrisisCrew.git
   ```
3. Move the project folder to:

   ```
   htdocs/ (XAMPP) or www/ (WAMP)
   ```
4. Open **phpMyAdmin**
5. Create a database named:

   ```
   crisiscrew20
   ```
6. Import the file:

   ```
   crisiscrew20.sql
   ```
7. Configure database connection in `db_conn.php`
8. Run the project in browser:

   ```
   http://localhost/CrisisCrew30-main
   ```
